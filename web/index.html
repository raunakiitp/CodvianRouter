      Breaker reset

      Live — POST /api/resilience/breakers/reset
      Resetting a breaker clears its counted failures and open window, so the provider is tried again at once. A provider that also holds a short-lived per-key Retry-After cooldown can still be skipped until that cooldown expires.
      Reset availability is read from the settings feed below — press Load settings to check it.

      Resilience settings

      Live — GET + PATCH /api/resilience/settings
      Settings are not loaded yet — press Load settings. A gateway key is needed (admin scope).
      These settings have no runtime backing, so they cannot be changed here: breaker_threshold, breaker_open_for_seconds and cooldown_seconds are range-validated and then answer 501 naming the field. Breaker threshold and open-for are read when the engine is built — change them in config and restart. Cooldown lengths come from the upstream Retry-After hint, so there is no global cooldown-duration knob.
