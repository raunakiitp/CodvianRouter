Codvian Router — API Try-It

Every route the router serves, generated from its guard route table. Requests go to this router only — never to a live provider. Destructive routes need their typed confirmation phrase as well as a key.

Your gateway key stays in this page's memory only. It is never stored (no localStorage, no cookies) and never sent anywhere except this router, as an Authorization: Bearer header. Close the tab and it is gone.

Connection

Base URL defaults to the origin this page was served from. Override it only to point at another router you operate.

Auth-exempt routes work with the key field empty. Scoped routes answer 403 without the right scope; LOCAL_ONLY routes answer 403 unless you open this page from loopback.
